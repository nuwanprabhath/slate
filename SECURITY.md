# Security policy

Slate holds people's notes, so a flaw that exposes them, or lets someone change them or the app,
matters to us.

## Reporting a vulnerability

Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/nuwanprabhath/slate/security/advisories/new),
not in a public issue. Include what you found, the version and platform, and the steps to
reproduce it. You will get a reply within a week. A fix is released as soon as it is ready, and you
are credited in the advisory unless you would rather not be.

## Supported versions

Only the latest release gets security fixes. Slate checks for updates itself, and every update is
signed and verified before it is installed.
